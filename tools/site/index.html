One bot for your whole Vector community

Moderation, levels, tickets, events, mini games and a web dashboard, set up from a single YAML file. It runs on your own machine with its own Vector account.

The dashboard is for the jobs that are easier with a mouse

Warn or time out a member, change a setting, read a ticket transcript or post an announcement without typing a command. Logins are a username and password, and each one is tied to a Vector account, so someone who loses their admin role in Vector loses dashboard access too.

How the dashboard works

Rank cards and leaderboards are pictures

Members get a card with their avatar, level and progress instead of a line of text, drawn in Vector's colours. The calendar works the same way: !calendar posts the month as an image.

From clone to running

  1. Install. On a Mac, ./install.sh sets up everything and starts the bot at login. On Linux, create a virtual environment and pip install -e ".[webhooks,dashboard]".
  2. Give the bot a role. In your community, give its account the permissions you want it to use. Without one it keeps running and tells you which permission is missing.
  3. Edit config.yaml. Turn modules on or off and change any number. python -m vectiq --check explains mistakes before you restart.
  4. Type !help in any channel.

The full getting started guide covers keys, invites and permissions.

One YAML file

One SQLite file

Its own account
